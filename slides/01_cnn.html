2 Learning from examples

2.1 Supervised learning

  • Examples \((x_i, y_i)\), \(i = 1, \dots, N\): a sequence \(x_i\) and its label \(y_i\) (1 bound, 0 unbound)
  • A model \(f_\theta\) with parameters \(\theta\) predicts \(\hat p = f_\theta(x)\), the probability of bound

2.2 The loss

  • Binary cross-entropy: \(\;\mathcal{L} = -\frac{1}{N}\sum_{i} \big[\, y_i \log \hat p_i + (1 - y_i)\log(1 - \hat p_i) \,\big]\)

2.3 Gradient descent

\[\theta \leftarrow \theta - \eta \, \nabla_\theta \mathcal{L}\]

  • On our data: \(\;\hat p = \sigma(w^\top x + b)\), \(\;x\) = (G+C fraction, U fraction)

2.4 The learning rate

  • \(\eta\) sets the size of each step

2.5 Mini-batches and epochs

  • Each step uses a batch of 256 sequences; an epoch is one pass over all 92,346 (360 steps)

2.6 From logistic regression to a neural network

  • A neural network stacks layers of units, with ReLU, \(\max(0, z)\), between them

3 Testing a model

3.1 Train, validate, test

  • Train: fit the weights
  • Validation: choose settings, such as the number of epochs
  • Test: report once
  • Today: 92,346 training and 1,000 held-out test sequences

3.2 AUROC

  • AUROC = the probability that a random bound sequence scores higher than a random unbound one. 0.5 is chance, 1.0 is perfect.

3.3 Noise in a held-out AUROC

  • On 1,000 test sequences, 95% of resampled AUROCs fall within about ±0.025

3.4 Overfitting

  • A model that scores much higher on its training data than on held-out data has overfit: it memorised its training examples. Report the held-out score
